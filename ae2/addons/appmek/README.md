# Applied Mekanistics 1.6.3

[Applied Mekanistics](https://github.com/AppliedEnergistics/Applied-Mekanistics) by ramidzkh, as All the Mods 10 ships
it (`Applied-Mekanistics-1.6.3.jar`). The jar carries no licence file; its `neoforge.mods.toml` says "See GitHub
repository for details", and that repository is LGPL-3.0, so the port's derived files carry the same terms. The
assets' licence is not stated; they are generated locally from the player's jar and never committed. Provenance in
[SOURCE_MANIFEST.json](SOURCE_MANIFEST.json), the declared content in [content.json](content.json), the design and
the slices in [docs/appmek.md](../../../docs/appmek.md).

`ATM10_DIR=... bun run ae2/scripts/prepare-addon.ts appmek`.
